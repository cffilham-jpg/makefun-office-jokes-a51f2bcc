A 53-character office joke turns an email CC into a forwarding address for blame. This stdlib-only Python program writes the UTF-8 line without a trailing newline to `entry.txt` in `MAKEFUN_OUTPUT_DIR`, or `out` by default, with a temporary-directory fallback.

## Run it

```sh
python3 main.py
```
